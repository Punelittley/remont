# Сайт монтажа кровли, заборов, сайдинга и окон («Кровля & Забор»)

Современный, премиальный и адаптивный одностраничный сайт (Landing Page) с эстетикой Bento Grid, реалистичными фотографиями с высоким разрешением, переключателем областных центров, векторными иконками и максимальной интеграцией со страницей ВКонтакте (`vk.ru/zabor_okno`).

## 🌟 Ключевые возможности и особенности

1. **Новый первый экран (Hero Section в стиле Bento Showcase):**
   - Лаконичный заголовок с акцентным бейджем региона.
   - Панорамная карточка объекта с эффектом масштабирования и плавающими стеклянными плашками (Glassmorphism):
     - *Гарантия 10 лет по договору*;
     - *Рассрочка 0% без первого взноса*;
     - *1 250+ сданных объектов*.
   - Интегрированные карточки 4 ключевых направлений (Кровля, Заборы, Сайдинг, Окна).

2. **Дизайн в стиле Bento Grid (по референсам):**
   - **Блок «Наша миссия и философия» (Референс 1):** Крупная карточка слева + сетка 2x2 преимуществ с закругленными углами.
   - **Блок ключевых показателей и метрик (Референс 2):** Цифровые показатели слева, центральная вертикальная карточка с фото коттеджа, описание справа.
   - **Карточки готовых решений (Референс 4):** «Для своего дома», «Для дачи и сада», «Для безопасности», «Под ключ с доставкой».
   - **Контрастный темный CTA-блок (Референс 3 High-Fidelity):** Стильный баннер для моментального вызова инженера на замер.

3. **Строгий и профессиональный стиль (без эмодзи):**
   - Все пиктограммы и маркеры заменены на чистые, масштабируемые векторные SVG-иконки.

4. **Города — Областные центры:**
   - Интерактивный модальный селектор более 30 областных центров (Вологда, Череповец, Ярославль, Кострома, Иваново, Владимир, Тверь, Нижний Новгород, Пенза, Самара, Саратов, Челябинск, Екатеринбург, Воронеж, Ростов-на-Дону, Краснодар и др.).

   - Сохранение выбранного города в `localStorage`.

5. **Максимум интеграции с ВКонтакте:**

   - Высокая скорость загрузки (< 1 секунды), отличные показатели Google PageSpeed.

Просто откройте файл `index.html` в любом браузере (Google Chrome, Яндекс Браузер, Safari, Edge).

## 📦 Как выложить сайт на GitHub Pages (Бесплатный хостинг)

1. Создайте новый репозиторий на [GitHub](https://github.com/new), например `krishasait`.
2. В терминале в папке `c:\Users\Nikolay\Desktop\krishasait` выполните команды:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: modern roofing & fence landing page"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/krishasait.git
   git push -u origin main
   ```
3. В настройках вашего репозитория на GitHub:
   - Перейдите во вкладку **Settings** -> раздел **Pages** (слева в меню).
   - В пункте **Branch** выберите ветку `main` и папку `/ (root)`.
   - Нажмите **Save**.
4. Через 1–2 минуты ваш сайт станет доступен всему миру по адресу:
   `https://ВАШ_ЛОГИН.github.io/krishasait/`
